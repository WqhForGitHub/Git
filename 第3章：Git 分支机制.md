### 3.1 分支机制简述

#### 1. 创建新分支

 现在假设你要创建一个名为 testing 的新分支。这可以通过 git branch 命令实现：

```powershell
$ git branch testing
```

它不会切换到新的分支上去。



#### 2. 切换分支

 要切换到已有的分支，可以执行 git checkout 命令。现在让我们切换到新建的 testing 分支上去，如下所示。

```powershell
$ git checkout testing
```
